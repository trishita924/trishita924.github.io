Free, responsive portfolio using only HTML, CSS and JavaScript.

## Before publishing
Open `index.html` and replace:
- `bhowmicktrishita924@gmail.com`
- `trishita924` in GitHub
- `trishita924` in LinkedIn

## Run
Double-click `index.html`.

## GitHub Pages
Create a public repository named `YOUR_USERNAME.github.io`, upload these three files, then enable Settings → Pages → Deploy from branch → main → root.
Your link will be `https://YOUR_USERNAME.github.io`.
